CAPABILITIES

Precision Punch-Hole Architecture

01 • GEOMETRY STUDIO

Universal Camera Cutout Calibration

Detects `DisplayCutout` bounds automatically and gives fine X/Y offset calibration so the capsule wraps cleanly around center or corner punch-holes without clipping status bar icons.

02 • TELEPHONY

3-State Call UI & Loudspeaker Routing

Smoothly transitions between compact live call pill, incoming answer/decline controls, and connected speakerphone routing built for Android 12+ audio APIs.

03 • LIVE ACTIVITIES

Live Music & Charging Pills

Interruptible spring-physics capsules for playback controls, real-time audio visualizers, Bluetooth peripheral battery alerts, and fast-charging telemetry.

04 • MASCOT STUDIO

Interactive Pixel Mascots

Bring your notch to life with DotCat, GlyphOrb, and TapeBuddy — lightweight Compose pixel companions reacting to idle, music, calls, charging, and taps.

05 • GAMING COMFORT

Game-Mode Auto-Hide

Automatically hides the floating capsule (`CATEGORY_GAME` or landscape immersive fullscreen) so HUD controls stay unobstructed and restores it the moment you exit.

QUICK SETUP

3-Step Installation

STEP 01

Download APK

Grab signed DotIsland-v1.0.0.apk from the latest GitHub Release using the button above.

STEP 02

Grant Core Permissions

Allow installing unknown apps, then enable Display over other apps and Notification access inside Dot Island.

STEP 03

Calibrate Cutout

Open Studios → Geometry Calibration to align the capsule around your front camera and tap Start Dot Island.
